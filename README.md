# US Superstore Sales & Delivery Performance Analysis

📊 Project Overview

An interactive Business Intelligence project built to analyze sales, profitability, and logistics performance for a major US retail chain using the Superstore Sales dataset (2020-2023). The project focuses on trend tracking, product-level profitability, and supply chain efficiency to support executive decision-making.

🛠️ Tools Used

* Tableau Public / Desktop — Data visualization and dashboard orchestration
* Tableau Calculated Fields — Advanced calculations for delivery durations (DATEDIFF) and relative profit margins

🔗 Links

* 📊 [Live Dashboard (Tableau Public)](https://public.tableau.com/app/profile/name.gamze.baker/viz/FinalProject_17752586202960/DeliveryDashboard)

📁 Tableau Dashboard Sheets

* Sales and Profit Time Series — Dual-axis month-over-month trend visualization with dynamic "Apply" filters for Ship Mode and Segment.
* Profitability Analysis — Hierarchical matrix showing profit percentages by Category, Sub-Category, and Ship Mode with a zero-centered diverging color scale and grand totals.
* Delivery Analysis Dashboard — Combined view tracking delivery efficiency, day distribution, and geographical performance.

📈 Key Findings

* Standard Class shipping takes the longest (avg ~5 days), while First Class and Same Day options successfully meet tighter operational timelines.
* Delivery day distribution peaks at 4 and 5 days, making this the critical threshold for supply chain and warehouse planning.
* Geographical mapping reveals that delivery times vary by state, with remote regions showing increased delivery times (highlighted by dark gradient scales).
